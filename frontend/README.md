# Frontend

DocuMind AI frontend built with React, Vite, TypeScript, Tailwind CSS, Axios, React Router, Recharts, Lucide React, and Framer Motion.

## Development

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run build
```

## Environment

Create `.env` from `.env.example`:

```powershell
Copy-Item .env.example .env -Force
```

Default API target:

```env
VITE_API_URL=http://localhost:8080
```
